# My Cloud Engineering Journey

I'm currently a Data Center Technician working toward transitioning into Cloud Engineering.

This repository documents my 60-day hands-on learning journey as I develop practical skills in Linux administration, networking, Python, Bash, AWS, Terraform, and infrastructure automation.

I'll be sharing what I learn, the challenges I encounter, and how I troubleshoot them.

## Learning Goals

- Strengthen Linux administration and troubleshooting skills
- Understand networking fundamentals
- Automate infrastructure tasks using Python and Bash
- Build and manage AWS cloud infrastructure
- Learn Terraform and Infrastructure as Code
- Complete a hands-on cloud infrastructure capstone project

## Progress

### Day 1 — Linux Fundamentals & Troubleshooting

- Identified Linux distributions, kernels, and system architecture.
- Monitored CPU and memory utilization using `top` and `free -h`.
- Investigated running processes using `ps` and `grep`.
- Learned how Linux pipes (`|`) work.
- Checked service status using `systemctl`.
- Investigated service logs using `journalctl`.
- Practiced troubleshooting a failed Python application and database connection.
